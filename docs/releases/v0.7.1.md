LocalMind 0.7.1 brings a warmer desktop workspace and a compact chat window.

### What's new

- Refreshed chat, sidebar and workspace styling, with light and dark themes and bundled DM Sans fonts.
- Mini chat: resize and pin the current conversation above other apps, minimize it, or expand it without losing the draft or restarting a response. Use Ctrl+Shift+M on Windows/Linux or Cmd+Shift+M on macOS while LocalMind is focused.
- A compact Tools menu for Memory, Knowledge and Web, plus editable starter prompts.
- Project-scoped memory and document retrieval, source inspection, and reviewed task creation.
- Tracked project dependencies with repair previews. Applying text-file repairs remains a Windows pilot with backups and recovery receipts.
- Release publication handles GitHub's temporary draft tag names and checks for tag conflicts before building installers.
- Interrupted responses keep the text already generated, with a separate explanation and retry action.
- Starting a new chat after expanding mini chat correctly clears the previous transcript.

### Install

| Computer | Download |
| --- | --- |
| Windows x64 | `LocalMind_0.7.1_x64-setup.exe` |
| macOS Intel, macOS 14 or later | `LocalMind_0.7.1_x64.dmg` |
| macOS Apple Silicon, macOS 14 or later | `LocalMind_0.7.1_aarch64.dmg` |
| Linux x64 | The `.deb` or `.AppImage` asset |

The installers include the local AI service and Ollama runtime. Model weights are downloaded separately. Existing local Ollama installations can be reused. Optional web search and remote connections send requests to their respective services.

Updater bundles are signed with LocalMind's update key. Windows installers are not Authenticode-signed, and macOS apps are not Apple-notarized. `SHA256SUMS.txt` contains the release checksums.

Voice is a synthetic interface preview; live speech recognition and synthesis are not available in this release. Mini chat compacts the current window rather than opening a second independent chat.
