LocalMind 0.7.0 updates the desktop workspace and fixes chat reliability.

### What's new

- Redesigned chat, navigation, settings, and workspace pages with light and dark themes.
- New LocalMind logo and bundled fonts.
- Source links and publication dates saved with answers.
- Better handling of follow-up searches, current news, interrupted replies, and retries.
- Per-user storage, safer migration of existing data, and recovery after a local service failure.
- Improved model setup, Knowledge search, Memory, Projects, Tasks, and Connections.

### Install

| Computer | Download |
| --- | --- |
| Windows x64 | `LocalMind_0.7.0_x64-setup.exe` |
| macOS Intel, macOS 14 or later | `LocalMind_0.7.0_x64.dmg` |
| macOS Apple Silicon, macOS 14 or later | `LocalMind_0.7.0_aarch64.dmg` |
| Linux x64 | The `.deb` or `.AppImage` asset |

The installers include the local AI service and Ollama runtime. Model weights are
downloaded separately during setup. An already running Ollama installation is
used when available. Model inference stays on your computer; optional web search
sends queries to the selected provider.

The updater bundles are signed with LocalMind's existing update key. Windows
installers are not Authenticode-signed, and macOS apps are not notarized by Apple.
Voice is not available in this release.

`SHA256SUMS.txt` contains checksums for the release files. `latest.json` supplies
signed update information for all four supported platforms.
