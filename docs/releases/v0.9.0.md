# LocalMind 0.9.0

Release candidate. Local Windows checks are complete except for native screenshot selection and updater installation. Signed installer checks across all supported platforms are still pending.

## Changes since 0.8.0

- Settings now includes Updates: check manually, see the installed version and release notes, retry failures, and confirm before installing and restarting. Update checks do not depend on the local AI service.
- Duplicate launches use the same profile's existing window. Windows background services belong to the app's process group, with startup failures and restart controls exposed in the workspace.
- Conversation handling keeps active chat history separate from retrieved memory and project context. Requests are tracked so cancelled or delayed responses cannot replace another turn.
- The answer policy distinguishes enabled web search from a search that found no usable evidence. It also tells the model not to treat today's date as its training cutoff.
- Local model settings expose supported thinking controls, context and response limits. Model readiness checks distinguish missing or incompatible models from service failures.
- Response preferences and answer feedback are explicit local controls. Memory can be inspected, edited and deleted.
- Chat accepts screenshot and document attachments, with ownership checks, previews and saved-message restoration. Vision requires a compatible model; OCR requires a separately installed engine.
- Optional cloud providers use user-supplied credentials and approved context scopes. Provider adapters have fixture coverage; this is not a claim that every provider/model combination has passed a live test.
- The visual workspace supports validated diagrams, charts and bounded interactive examples. Arbitrary generated code is not enabled.
- Contract tests cover stored messages, attachments, interrupted responses and provider events. Database checks run across Windows and macOS in addition to Linux CI.

## Updating

Existing v0.8.0 installations can use the update banner once this release is published. The manual Updates page becomes available after installing 0.9.0. Finish active responses and save unsent drafts before updating.

Chat models download separately. An existing Ollama installation can be reused. Updating the application does not replace model weights or train the model.

## Limits

Voice, media generation and connected-app workflows retain their documented pilot and consent requirements. Local image generation remains disabled unless its quality gate passes. Paid provider calls require your own account and explicit approval. No shared account service or automatic cross-device synchronization is included.

Local model quality still varies. The release trial retained the correct topic across follow-ups and read a synthetic screenshot, but greetings remained formulaic and a generated flowchart contained an incorrect loop. Web search can return no sufficiently recent, dated evidence. These checks do not establish general answer accuracy or a guaranteed response time.

Updater bundles require the existing LocalMind signing key. Windows Authenticode signing and Apple notarization are not configured. Platform-specific installer and updater acceptance must be recorded before this candidate is published.
